# Note Management System

The **Note Management System** is a simple Java-based application for managing notes. It allows users to register, log in, create, view, edit, and delete notes. Administrators can add and delete users.

## Key Features

- **User Authentication**: Users can log in using their credentials.
- **Note Management**:
  - Add new notes.
  - View all notes.
  - Edit existing notes.
  - Delete notes.
  - Search notes by ID or title.
- **Admin Interface**:
  - Add new users.
  - Delete users.

## Technologies

- **Java**: The primary programming language.
- **MySQL**: Database for storing users and notes.
- **JDBC**: For database interaction.
